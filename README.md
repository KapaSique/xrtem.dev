# xrtem.dev

Stelmah's portfolio — a kinetic developer profile built around real GitHub activity and selected systems work.

## Run locally

```bash
npm install
npm run dev
```

## Stack

- React 19 + TypeScript + Vite 8
- Motion for interaction and scroll-linked animation
- Lenis for smooth scrolling
- React Activity Calendar with a live KapaSique feed and verified offline snapshot
- Local Bricolage Grotesque and IBM Plex Mono fonts

## Data

The contribution calendar refreshes from the public GitHub contributions API in the browser. If that API is unavailable, the page uses a compact snapshot captured from GitHub GraphQL on 2026-07-17.
